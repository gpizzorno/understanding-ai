# Unit 3 Workshop Resources

Shared resources for running the Unit 3 case study as a workshop.

These links point to Google Drive and a Google Sheet owned by the original instructors. Replace them with your own copies when running your own workshop. To use a shared sheet with the notebook, publish it as CSV (`File → Share → Publish to web → CSV`) and paste the URL into `SHEET_CSV_URL` in Section 9.
